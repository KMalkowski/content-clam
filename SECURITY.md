# Security

Please don't open a public issue for a security problem. Report it privately through [GitHub's vulnerability form](https://github.com/KMalkowski/content-clam/security/advisories/new) instead.

These are the problems we most want to hear about:

- One account reading or changing another account's settings, credits, or purchases.
- Getting credits without paying, or being charged more than once for one analysis.
- Video data or analysis results reaching the server's database or logs.
- A personal TypeSafe key leaving the device.
- A YouTube page injecting HTML or script into the extension.

I'll reply within a week. Once a fix ships, I'll credit you in the release notes unless you'd rather stay anonymous.

Only the latest release of the extension and the current `main` branch get security fixes.
