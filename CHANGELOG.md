# Changelog

Notable changes to Content Clam. Versions follow the extension version in `extension/package.json`.

## Unreleased

First public version, not yet in the Chrome Web Store.

- Dim YouTube videos that match categories you choose. Each dimmed video shows the reason and a Reveal button.
- Six default categories, including clickbait and outrage bait. You can edit them or add your own.
- Allowed topics and allowed channels that are never dimmed.
- Videos from channels you subscribe to stay visible by default.
- A Hide Shorts switch that removes Shorts without using any analyses.
- Pause a matching Short until you press Reveal.
- Pay with your own TypeSafe API key, or buy credits from the hosted service.
- Sync settings across devices when signed in. Classification results stay on the device.
- Settings export and import as JSON.
- A popup that shows how many videos and Shorts were hidden this week. You can edit a category's name and description there, and undo a removal.
